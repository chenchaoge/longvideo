# 动画制作原则

## 必须提前知晓来自用户的最少信息如下

- 需要制作的视频动画时长大概多久
- 横版视频还是竖版视频
- 用户希望视频想要表达的主题

## 收到用户信息后

- 先彻底阅读用户给的所有东西，并完整通盘的理解用户想表达的内容：视频是什么类型、什么题材，文稿哪些是要念的、哪些要出现在画面上、哪些只是内容说明；
- 怎么创作完全自由发挥，skill 不给创作方向，也不提供现成的画面样式、配乐风格和音效；
- 制作的动画视频，需要包括音效和音乐。动画内容、音效、音乐等怎么安排需要你通盘自行考虑；
- 你可以使用任何你觉得合适的工具和技术，做出最好最惊艳的效果：画面、配乐、音效用什么技术栈完全由你定，不限于本 skill 引擎自带的 Canvas 2D 和 synth 合成；要根据视频主题和文稿、剧本内容深度思考用什么技术做得最好；
- 默认不要使用除了本skill外的其他任何视频制作类skill
- 默认不要参考以前做过的视频或者文案，除非用户明确有要求
- 视频横版、竖版动画出片格式标准：references/视频动画出片格式标准.md

# 装软件（开工检查报「要处理」时照这里装；Windows、Mac 分开写）

## 谁来装
- Windows：winget 命令用户同意后 AI 代跑
- Mac：安装包（.pkg、.dmg）和 Homebrew 本身要用户自己装（要输电脑密码，AI 代跑不了）；Homebrew 装好后，brew 命令用户同意后 AI 代跑
- 装完要重开终端或 AI 平台才找得到新装的命令，再跑一次开工检查，到「都通过了」为止

## OpenChatCut（只有 Mac 要装）
- 从 [官方发布页](https://github.com/0xsline/OpenChatCut/releases)下载适合本机芯片的 macOS 版：M 系列芯片下 arm64 的 .dmg，Intel 芯片下 x64 的 .dmg（看芯片：左上角苹果图标 →「关于本机」）；打开后拖进「应用程序」文件夹
- 装好后第 1 步连接，见 `OpenChatCut操作.md`「连接」

## Python（3.11 或更新）
- Windows：`winget install Python.Python.3.13`
- Mac：自带的 python3 是 3.9，不够；到 python.org 下载 macOS 安装包（.pkg）装
- 官方源下载失败（国内常见）：从 `https://registry.npmmirror.com/-/binary/python/` 进最新的 3.13.x 文件夹下载，Windows 下 `python-3.13.x-amd64.exe`，Mac 下 `python-3.13.x-macos11.pkg`
- 装好后这台电脑的 Python 命令怎么找：见工具用法.md「调用」

## Node.js（18 或更新）
- Windows：`winget install OpenJS.NodeJS.LTS`
- Mac：到 nodejs.org 下载 macOS 安装包（.pkg）装
- 官方源下载失败：从 `https://registry.npmmirror.com/-/binary/node/` 进最新的 LTS 版本文件夹下载安装包（Windows 下 x64 的 .msi，Mac 下 .pkg）

## ffmpeg（要带 ffprobe，能烧字幕、能写字）
- Windows：`winget install Gyan.FFmpeg`（完整版，带烧字幕要的 libass）
- Mac：先装 Homebrew（照 brew.sh 首页那行命令，用户自己在终端里装），再 `brew install ffmpeg`
- 开工检查报「缺 subtitles、drawtext 功能」：装的是精简版，照上面换一个

## 浏览器（渲染画面用）
- Windows：系统自带的 Edge，不用装
- Mac：Edge 或 Chrome 装一个，放「应用程序」文件夹；Chrome 国内从 google.cn/chrome 下载 .dmg
- 找哪些位置、先找哪个：`scripts/browsers.json`

## 字体（思源黑体、思源宋体）
- 要 Google 版的 Noto Sans SC、Noto Serif SC；Adobe 版叫 Source Han，画面认不到，渲染会报缺字体
- 从 Google Fonts（fonts.google.com）搜这两个名字下载，解压后：
  - Windows：右键字体文件 →「为所有用户安装」或「安装」
  - Mac：双击字体文件 →「安装字体」

## 装好软件后（skill 自己用的库）
- 在 skill 的 `scripts/` 里跑：`npm install`，和 `<Python 命令> -m pip install -r requirements.txt`

# 工具用法（scripts/）

## 调用（cd 到工作目录，用 Bash 管道喂菜单，不能用 PowerShell 管道）
```
cd 用户工作目录
printf "1\n" | node <skill目录>/scripts/render.mjs
printf "4\n" | PYTHONDONTWRITEBYTECODE=1 PYTHONIOENCODING=utf-8 python -u <skill目录>/scripts/audio/make_audio.py
printf "3\n" | PYTHONDONTWRITEBYTECODE=1 PYTHONIOENCODING=utf-8 python -u <skill目录>/scripts/jianying/draft.py
printf "1\n" | node <skill目录>/scripts/clean.mjs
printf "1\n素材/头像.jpg\n" | PYTHONDONTWRITEBYTECODE=1 PYTHONIOENCODING=utf-8 python -u <skill目录>/scripts/avatar.py
```
draft.py 菜单（默认直接读写草稿，兜底才用 3、4；见剪映操作.md）：
- 8 查剪映装没装：只看注册表里的安装信息，不碰草稿；第 1 步开场核对时跑，结果只记进度记录
- 1 生成配音草稿（只导入初版 SRT）　2 生成配音草稿（初版 SRT + 顶层的配音文件）
- 5 检查加解密：剪映的加解密自检 + 解开最近一个加密草稿；过不了按剪映加解密.md 处理
- 6 A1 在草稿里直接对齐（要先退出剪映）：备份成 `<草稿名>_备份`（只留一份，已有的换成这次改之前的样子），每段配音的长度直接从草稿读，配音段从 0 秒首尾相接、只挪不剪，字幕起止改成和它那段配音一样；出 `工程文件/配音.wav`（按草稿位置拼的副本）、`字幕.srt`；字幕和配音段数对不上就停下、草稿不改；已有上次的 `字幕.srt` 就逐条列出这次改了什么（字幕和配音都改了、只改了字幕、只换了行、加删句子），只改字幕、配音没重新生成的不算对不上
- 7 成片放进草稿（要先退出剪映）：顶层最新的 `<片名>_<序号>.mp4` 放进配音草稿视频轨、从 0 秒起，配音轨静音；旧版成片自动换掉
- 3 兜底对齐：用顶层剪映导出的整条音频和字幕，按每条字幕的起点量出每段配音停在哪，只删段与段之间的空白，字幕时长改成和配音一样长；没导出字幕时会问，用户确认没改过字幕就输入 y 用初版 SRT；出 `工程文件/配音.wav`、`字幕.srt`
- 4 兜底导回：菜单 3 跑完接着跑（草稿要先关掉、回到首页），原配音草稿改名备份成 `<草稿名>_备份`，原名字新建草稿导入对齐好的字幕和配音（配音按字幕切成一段一段）
后续提问接着喂：`printf "3\n1.5,10\n"`

## render.mjs 菜单
- 10 文本转 UTF-8：工作目录顶层和一级子目录（工程文件/ 除外）里的 txt、md、srt、csv，不是 UTF-8 的（记事本存的 ANSI 即 GBK、UTF-16）原地转成 UTF-8，原件备份到 `工程文件/原编码备份/`；第 1 步看用户文件前先跑
- 9 文稿转字幕：转开场核对.json 里 voiceScript 指的要念的文字稿（非口播类的台词稿，或口播类文稿不是 TXT 时提取的文字版），没有就转整篇文稿 script（口播类，只认 TXT，别的格式先提取成文字版填进 voiceScript）；稿不是 UTF-8 会先自动转；draft.py 取稿的规则一样
- 10 只管纯文本的编码；DOCX、PDF 这类别的格式按格式自己读，要用的库或工具自己装
- 11 配音字幕预览：第 4 步只有 B（配音没经过剪映）对齐后跑，A1、A2 让用户在剪映草稿里看、不出 MP4；用 `工程文件/` 里对齐好的配音和字幕（初版 SRT 不算）在顶层出 `配音字幕预览.mp4`（深灰底，字幕样子和成片一样），给用户确认；顶层已有旧预览会问要不要覆盖
- 0 初始化：最大号的稿还没有 project.json 就初始化它（没有稿就建第一稿）；配音和字幕先找本稿目录（非口播类拼好的），再找 工程文件/（A1、B 对齐好的，或 A2 剪映导出的）；图片找工作目录；场景文件是空的。已有 project.json 就复制成下一稿（中间文件不带，project.json 里的路径自动改成新稿）
- 1 渲染全片：分段并行，中断可续渲，改过脚本或素材自动重渲；有配音的先核对配音长度和 project.json 的 duration，对不上就停　2 渲染片段
- 3 抽帧检查（秒数逗号分隔）→ 本稿 `中间文件/check/`
- 4 导出音效、采样、配乐闪避的事件表（混音前必跑）　6 预览 http://127.0.0.1:8765/
- 5 出片　7 质检（总览图在本稿 `中间文件/qa/sheet_*.png`）　8 抽实机片段帧

## make_audio.py 菜单
1 配乐　2 音效轨　3 混音　4 全部　5 采样轨；有配音时自动给人声让位，响度统一 -14 LUFS

make_audio.py 只负责把做好的声音按时间摆好、混音，不管配乐、音效用什么做。用什么技术栈由你按视频主题定（见做动画.md 第 2 小步），交给它的方式有两种：
- 直接交音频文件：配乐填 `music_file`，音效填 `sfx_files`（见下面 project.json）；任何工具做的、ffmpeg 能读的格式都行，自动转成 48k 立体声。做好的文件放本稿目录
- 写 Python 脚本：
  - 配乐脚本（music_py）：提供 `build(cfg, total)`，返回立体声 numpy 数组 (n,2)（采样率 48000，长度 total 秒）或音频文件路径
  - 音效脚本（sfx_py）：提供 `LIB = {音效名: 函数(rng) → 立体声数组或音频文件路径}`；可选 `LEVEL = {音效名: 基础音量}`（默认 1）、`VARIANT = {每次随机变化的音效名}`
  - 两种脚本里都能直接用 `c(n)`、`ce(n)`：第 n 句字幕的起止秒（和场景脚本一样，读 project.json 的 subs）；配乐换段、重音、停顿都用它写，不写死秒数；脚本里别把 c、ce 用作自己的变量名，会把它们盖掉
  - 脚本里可以用任何 Python 库、调用外部工具；也可以 `from synth import …` 用自带的合成零件：振荡器 sine saw square tri noise、包络 exp_env adsr bell、滤波 lowpass highpass bandpass sweep_filter、reverb pan stereo place fade normalize soft_clip、SR、midi_hz

## project.json（在本稿目录里，路径都相对工作目录，如 `工程文件/第一稿文件/场景脚本/s1.js`）
- `voice` `subs` `duration`：初始化自动填　`scripts`：场景脚本，按顺序加载
- `images`：{键名: 路径}　`fontLoads`：要用的系统字体（CSS font 写法）
- `libs`：第三方库，按顺序在场景脚本之前加载：`"路径"` 普通脚本，`{"src": "路径", "as": "全局变量名"}` ES 模块　`importmap`：{模块名: 路径}　`assets`：场景脚本自己读的文件或文件夹（改了会自动重渲）；用法见场景脚本速查.md「用别的技术」
- 配乐（必填，二选一）：`music_file` 做好的配乐文件，或 `music_py` 配乐脚本
- 音效（用了 sfx 就必填，可并用，同名以 sfx_files 为准）：`sfx_files` {音效名: 做好的音效文件}，或 `sfx_py` 音效脚本
- `mix`：混音电平 {music, sfx, samples}（dB）；无配音默认 0、-8、-6，有配音时 music、sfx 是在按人声自动算好的电平上再加减（默认 0），samples 默认 -6
- `clips`：实机录像片段 {键名: {file, ss, dur, crop}}，录像放 `素材/`
- `cuts`：[[起, 止]] 剪掉某段，只用于无配音项目
- `engine`：只有旧项目才有，指向项目里存的旧版引擎快照；新项目不填

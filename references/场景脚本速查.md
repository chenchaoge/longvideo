# 场景脚本速查（引擎源码在 scripts/js/，拿不准就读源码）

引擎只有底层能力，没有任何现成的画面样式：背景、配色、入场退场、镜头运动、转场、特效、图标、图形都自己做。每帧最后落在一块画布上，怎么画上去不限：用 Canvas 2D 直接画，或用任何浏览器能跑的技术、任何外部工具（见「用别的技术」）。

## 基本
- 画布横版 1920×1080、竖版 1080×1920（按 project.json 的 orientation，菜单 0 从开场核对带过来），30 帧；时间单位秒
- 常量：W、H 画布宽高，CX 画面中线，CY 内容中心（横版 460，竖版 770），PORTRAIT 是否竖版
- 竖版只用主要内容区 x 180～900、y 250～1600，中心 y 925（自己写常量用，CY 是有字幕时的中心）；有字幕的项目只到 y 1290（见出片格式标准）
- 每帧先清成黑底，再按顺序画各场景，最后画顶层元素
- 字幕时间：`c(i)` `ce(i)` 是第 i 句的起止秒，`CUES[i].text` 是原文，i 从 1 开始；`DUR` 是全片时长
- 时间点一律从字幕时间算，不写死秒数：场景、元素、章节标签、转场都写成 c(i)、ce(i)（句子中间的按比例从这两个算），结尾用 DUR；这样配音一改（某句重新生成、变长变短），画面自动跟着挪；只有确实和句子无关的才写秒数
- 每个场景文件：`BUILD.push(() => { scene(t0, t1, opts, () => { ...元素... }) })`；要在构建前准备的东西放 `PREP.push(fn)`，要等加载的放 `SETUP.push(async () => {})`
- 几段共用的函数放本稿 `场景脚本/` 里自己的公用文件，在 scripts 里排最前面

## 时间轴
- `scene(t0, t1, {cam, camX, camY}, build)`：一组元素；cam(lt, t) 返回 {s, x, y, r} 给整组加缩放、位移、旋转，camX/camY 是变换中心（默认 CX/CY）
- `el({t0, t1, x, y, z, sc, rot, alpha, over, sfx, draw})`：t0 ≤ t < t1 时调用 draw(g, a)，到点就没；z 是同场景内的叠放次序；over: true 放到顶层（不受场景镜头影响）
  - a.t 全片时间　a.lt 元素内时间　a.dur 元素时长　a.p 元素内进度 0～1（线性）
  - 淡入淡出、位移、缩放等动画都在 draw 里按时间自己算
- 缓动 `E.lin` `E.outC` `E.ioC` `E.outE` `E.outB` `E.outEl` 等；`P(t, t0, 时长, 缓动)` 区间进度；`kf(t, [[秒, 值]...], 缓动)` 关键帧
- `clamp` `lerp` `inv` `TAU` `rng(种子)` 可复现随机数　`hash(n)`　`fmt(数字)` 千分位

## 文字和图形
- `txt(g, '文字{强调1}[强调2]', x, y, o)`：o 有 size weight fam color hl hl2 align(center/left/right) ls(字距) lh(行高) stroke strokeW shadow shadowX shadowY glow
  - `each(i, n, ch)` 逐字回调，返回 {a, dx, dy, s, r, color} 调第 i 个字，返回 null 不画这个字（逐字动画自己写）
  - `textW(g, 文字, size, weight, fam)` 量宽度
- 字体：`F.zh` 思源黑体、`F.serif` 思源宋体，只用这两种；用到的字重、字号写进 project.json 的 fontLoads
- `rr(g, x, y, w, h, r)` 圆角矩形路径；`hexA('#rrggbb', 透明度)` 转 rgba
- 图片：`IMG[键名]` 是 project.json images 里加载好的图，用 `g.drawImage` 自己画
- `markImage(键名, t0, t1)`：素材说明里的图片出现时登记时间，成片质检会在前后抽帧核对
- `Clip(t0, 键名, o)` 放实机片段（clips 要先用菜单 8 抽帧）：o 有 t1 x y w h r(圆角) src(源裁切) ss speed map(t→源时间，可定格、变速、倒放) filter frame(g, a, w, h) count:false

## 用别的技术
- 用什么技术栈由你根据视频主题和文稿、剧本内容深度思考后定（见做动画.md 第 2 小步），不因为引擎自带就默认用 Canvas 2D；下面是各种技术怎么接进来
- 唯一要求：每一帧只凭时间 t 就能画出来，而且每次画出来都一样。出片时是几段同时渲染、中断了还能接着渲，所以不能靠真实时钟、requestAnimationFrame、setTimeout、CSS 动画、没设种子的随机数来推进画面；物理模拟这类要逐帧累积的，在 SETUP 里按时间先算好存起来，画的时候按 t 取
- 第三方库：下载到 `工程文件/库/`（npm 或从 CDN 下），填进 project.json，在场景脚本之前加载
  - `libs`：`"路径"` 按普通脚本加载，库自己挂到全局（如 p5、gsap、lottie）；`{"src": "路径", "as": "THREE"}` 按 ES 模块加载，导出挂到全局变量 THREE
  - `importmap`：`{"three": "路径"}`，让库里 `import 'three'` 这类写法找得到（three.js 的扩展要用）
  - 路径也可以写网址，但渲染时要联网，优先下载到本地
- 异步准备：`SETUP.push(async () => {})` 加载模型、贴图、初始化库，构建场景前等完；`FRAME_PREP.push(async (t) => {})` 每帧渲染前等完
- WebGL、three.js：用自己的离屏画布渲染；在 el 的 draw 里先按 a.t 摆好状态、render，再 `g.drawImage(那块画布, ...)` 贴到主画布。无头 Edge 用显卡跑 WebGL
- SVG、HTML：转成图片（SVG 字符串 → Blob → Image；HTML 用 SVG 的 foreignObject 包起来），在 FRAME_PREP 里等这一帧的图片加载好，draw 里 drawImage
- 浏览器外的工具（Manim、Blender、Python 画图、ffmpeg 等）：先做成视频或图片放进本稿目录，视频按实机片段 clips 放进来，图片填进 images
- 场景脚本自己读的文件（模型、贴图、SVG、数据，库除外）登记进 project.json 的 `assets`（文件或文件夹都行），改了才会自动重渲

## 声音
- `sfx(名字, t, 音量, 声像)`：名字是本稿 project.json 的 sfx_files 或音效脚本（sfx_py）的 LIB 里定义的音效；el 的 sfx 字段也能写
- `sample(t, 文件, {ss, dur, g, p, fi, fo, rate, norm})` 用现成音频（游戏原声、实机原声等）
- `duckMusic(t0, t1, 倍数)` 临时压低配乐
- 配乐、音效用什么技术栈做由你按视频主题定，不限于自带的 synth 合成：任何工具做好的音频文件直接填 music_file、sfx_files，或写 Python 脚本（接口见工具用法.md）

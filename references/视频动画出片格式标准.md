# 视频动画出片格式标准（横版 / 竖版）

以后所有成品一律按这个标准直接出片，不再另外压缩。有字幕的项目一次出两版：无字幕版（导回剪映用）和带字幕版（烧好 SRT 字幕，可直接发）；无字幕项目只出无字幕版。

## 一、共用标准

| 项目 | 标准 |
|---|---|
| 帧率 | 30 帧/秒 |
| 视频编码 | H.264（x264 编码器） |
| 压缩档位 | slow（越慢压得越小，画质不变） |
| 动画优化 | 打开（tune animation，专门给动画片用） |
| 画质参数 | CRF 23（数字越小画质越高、文件越大） |
| 码率上限 | 不设 |
| 音频 | AAC，256k，48kHz，双声道 |
| 字幕 | 无字幕版不烧；带字幕版烧 SRT（思源黑体 Bold 白字黑边） |
| 容器 | mp4，开 faststart（网页可边下边播） |
| 存放 | 用户工作目录顶层，文件名"片名_序号.mp4"，带字幕版"片名_序号_字幕.mp4"（目录里没有就是 _1，有就在最大序号上加 1，不覆盖旧版） |

## 二、横竖版区别（像素按母版算，留空取值偏保守）

| 项目 | 横版（长视频） | 竖版（抖音短视频） |
|---|---|---|
| 母版 | 1920×1080 | 1080×1920 |
| 成片 | 6 分钟以内不缩，1920×1080（1080P）；超过 6 分钟缩到 1280×720（720P） | 不缩，1080×1920 |
| 顶部留空 | 不用 | 最上面 250，放状态栏、顶部标签 |
| 底部留空 | 最底下 160 给字幕 | 最底下 400，放昵称、文案、音乐条 |
| 右侧留空 | 不用 | 最右边 140，放点赞、评论、分享按钮 |
| 字幕 | 四项指标（按剪映草稿里的字幕定）：字号 80；位置横向居中、贴底；字的下沿离底 97（目标 98，参数只有整数档取不到）；一行容许宽 1710 像素（左右各空 105），超过才折行。按实测：一个字约 55 像素宽，30 个字一行约 1654 像素、不折行（31 个字还放得下，32 个字折两行），白字上沿 y 931、下沿 y 982、中心 y 956（含描边 924～989），在底部留空 160 之内 | 字号 63；按实测：一个字约 43 像素宽，居中，下沿 y 1510（在底部留空区上沿之上）；放不下自动折两行，两行时上沿到 y 1406；左右在 188～891 之内 |
| 主要内容区 | y 920 以上 | x 140～940，y 250～1360 |

## 三、实测效果（横版 0919 动画带字幕版，555 秒；不烧字幕会略小）

- 文件 92.8 MB，平均码率 1.4M
- 压一次 3 分钟
- 画质打分（VMAF，满分 100）97.2～97.4；旧参数（CRF 20、medium）是 97.6～97.8，文件却大 4 倍多，肉眼看不出差别
- 竖版只做过 12 秒的流程测试：成片 1080×1920，字幕位置、自动折两行都对；文件大小、画质打分还没测

## 四、为什么这么定

- 压低码率上限没用：旧参数平均才 6M，10M 上限根本碰不到；压到 3M 文件减半，但复杂画面画质掉得比新标准还多
- 省体积主要靠"动画优化 + slow"：大片纯色背景和细噪点不再白白吃码率
- 不用 H.265：实测文件没更小、画质更低，部分平台和播放器不支持
- 横版超过 6 分钟缩到 720P：10 分钟左右的视频文件不会太大，适合上传国内短视频平台；文件太大平台会再压缩一次。6 分钟以内体积不大，出 1080P
- 先按 1080P 母版渲染再缩：画面坐标、字幕区、留空都按母版写，横竖版一套数；大图缩小线条和小字更平滑；母版留着，想出 1080P 不用重渲
- 竖版不缩：抖音竖版常规规格就是 1080×1920，手机全屏看，短视频体积也不大
- 竖版留空：抖音界面会盖住顶部、底部和右侧，关键内容放进去会被挡
- 横版字幕四项指标（2026-10-10 定）：字号 80（从 63 改大）；位置、离底、容许宽度照剪映草稿里字幕的样子定（草稿里字的下沿离底 98、文本框宽约 1706，烧字幕取最接近的整数档：离底 97、容许宽 1710）；一行最多 30 个字约 1654 像素，放得下不会折行；一行字加描边最高到 y 924，所以底部留空从 150 加到 160，主要内容区 y 920 以上
- 竖版字号仍是 63，暂不跟着横版改

## 五、出片流程

1. 画面先按母版尺寸高画质渲染（只做中间文件，不直接发）
2. 母版 + 混好的音频出成片：横版超过 6 分钟一步缩放到 720P，6 分钟以内和竖版不缩放
3. 出完做质检：核对时长、分辨率，抽帧看图片出现时间和画面文字清晰度

## 六、ffmpeg 命令

横版（超过 6 分钟；6 分钟以内去掉 `-vf "scale=..."` 这一行）：
```
ffmpeg -i 母版.mp4 -i 混音.wav -map 0:v -map 1:a
  -vf "scale=1280:720:flags=lanczos"
  -c:v libx264 -preset slow -tune animation -crf 23 -pix_fmt yuv420p -r 30
  -c:a aac -b:a 256k -shortest -movflags +faststart 成片.mp4
```

竖版：去掉 `-vf "scale=..."` 这一行，其余相同。

带字幕版：横版在 -vf 的缩放后面再接（不缩放时直接 `-vf "subtitles=..."`） `subtitles=字幕.srt:fontsdir=字体目录:force_style=...`；竖版加 `-vf "subtitles=..."`。样式见 render.mjs 的 SUB_STYLE（横版 FontSize 21.33 ≈ 1080P 画面 80 像素，720P 时随画面缩到 53 像素；MarginV 23 = 离底 97，MarginL、MarginR 21 = 左右各空 105、一行容许宽 1710，720P 时都按比例缩）；竖版不能照搬横版这套（字号随画面高度缩放，照搬字会变很大），要单独设一套（实测 FontSize 9.6：一个字约 43 像素宽；下沿 y 1510，两行时到 y 1406，左右在 188～891 之内）。

工具里对应：`scripts/render.mjs` 菜单 5「出片」，按 project.json 的 orientation 自动分横竖版，横版按母版时长自动定 1080P 还是 720P。
